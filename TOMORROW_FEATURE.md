# Нова функція: Відображення графіка Tomorrow

## 📅 Що було додано:

### Окремий блок для графіка на завтра
Тепер додаток показує **ДВА** графіки одночасно:

1. **Основний графік (Today)** - вгорі сторінки
   - Показує поточний графік на сьогодні
   - Якщо Today немає, але є Tomorrow - показує Tomorrow як основний
   - Якщо немає жодного - показує "✅ Сьогодні графіки відключень не застосовуються"

2. **Графік на завтра (Tomorrow)** - внизу сторінки
   - **ЗАВЖДИ** відображається окремим блоком
   - Має заголовок "📅 Графік на завтра"
   - Якщо Tomorrow є - показує зображення та HTML
   - Якщо Tomorrow немає - показує "📭 Ще немає графіка на завтра"

## 🔍 Технічні деталі:

### Нові поля в MenuData interface:
```typescript
interface MenuData {
  // ...існуючі поля...
  
  // Нові поля для Tomorrow:
  tomorrowDesktopImageUrl?: string;
  tomorrowMobileImageUrl?: string;
  tomorrowDesktopHtml?: string;
  tomorrowMobileHtml?: string;
  hasTomorrow?: boolean;
}
```

### Відображення:
- Tomorrow блок показується тільки коли `!menuData.isShowingTomorrow`
- Це означає: коли Tomorrow НЕ є основним графіком
- Використовується fallback для mobile/desktop зображень
- Підтримує темну/світлу теми

## 📱 Підтримка Mobile/Desktop:

- **Desktop**: показує `tomorrowDesktopImageUrl` та `tomorrowDesktopHtml`
- **Mobile**: показує `tomorrowMobileImageUrl` та `tomorrowMobileHtml`
- **Fallback**: якщо mobile версія відсутня - показує desktop і навпаки

## 🎨 Дизайн:

### Розділювач
- Між Today та Tomorrow є border-top (лінія розділу)
- Додатковий відступ (mt-8 pt-8) для візуального розділення

### Tomorrow блок має:
- Заголовок: "📅 Графік на завтра" (великий, жирний)
- Зображення з rounded corners та shadow
- HTML контент з центруванням тексту
- Або повідомлення "📭 Ще немає графіка на завтра" (якщо немає даних)

## 🔔 Сповіщення:

Сповіщення показуються коли змінюється:
- ✅ Today графік
- ✅ Tomorrow графік
- ✅ Архів графіків

Tomorrow відстежується окремо через хешування у функції `createScheduleHash()`.

## ✅ Переваги нової функції:

1. **Передбачуваність** - користувачі бачать графік на завтра заздалегідь
2. **Зручність** - не потрібно чекати до завтра щоб побачити графік
3. **Повна інформація** - і сьогодні, і завтра на одній сторінці
4. **Інтуїтивний UI** - чітке розділення між Today та Tomorrow
