# 🧪 Інструкція для тестування фонових сповіщень

## Швидкий тест (5 хвилин)

### Крок 1: Підготовка
1. Відкрийте додаток у браузері
2. Дозвольте сповіщення (натисніть "Дозволити сповіщення")
3. Відкрийте DevTools (F12) → вкладка Console

### Крок 2: Скидання історії
1. Натисніть кнопку **"🗑️ Скинути історію (тест)"**
2. У консолі побачите: `🗑️ Історія скинута!`

### Крок 3: Збереження першого стану
1. Натисніть **"🔄 Оновити зараз"**
2. У консолі побачите:
   ```
   💾 Збережено previousScheduleHash в localStorage: T:...
   💾 Збережено previousArchiveHash в localStorage: ...
   ```
3. Відкрийте **"🔍 Діагностична інформація"** → має показати "✅ Збережено"

### Крок 4: Перезавантаження сторінки
1. Натисніть F5 або Cmd+R (перезавантажити)
2. У консолі побачите:
   ```
   📦 Завантажено previousScheduleHash з localStorage: T:...
   📦 Завантажено previousArchiveHash з localStorage: ...
   ```
3. ✅ **Це підтверджує що хеші зберігаються між перезавантаженнями!**

### Крок 5: Імітація зміни даних
1. Скиньте історію ще раз: **"🗑️ Скинути історію (тест)"**
2. Дочекайтеся автоматичного оновлення (1 хвилина) АБО натисніть **"🔄 Оновити зараз"**
3. Якщо дані на сервері змінилися → **отримаєте сповіщення!** 🔔

### Крок 6: Тест фонового режиму
1. Згорніть вікно браузера / перейдіть на іншу вкладку
2. Дочекайтеся автоматичного оновлення (max 1 хвилина)
3. Якщо дані змінилися → **отримаєте сповіщення навіть у фоні!** 🔔

## 🔍 Що перевіряти в консолі

### ✅ Успішне збереження:

## 🚨 Можливі проблеми та рішення

### Проблема 1: "previousScheduleHash: ❌ Відсутній"
**Причина:** localStorage порожній або очищений
**Рішення:** Натисніть "🔄 Оновити зараз" - хеш збережеться

### Проблема 2: Сповіщення не показуються
**Перевірте:**
1. Дозвіл на сповіщення: має бути "granted"
2. У консолі є `🔔 ГРАФІК ЗМІНИВСЯ!`?
   - ✅ Є → проблема з Notification API
   - ❌ Немає → дані не змінилися

### Проблема 3: localStorage не зберігається
**Перевірте:**
1. Браузер у режимі інкогніто? → localStorage не працює
2. У консолі є `💾 Збережено previousScheduleHash...`?
3. Перевірте DevTools → Application → Local Storage → ваш домен

## 📊 Моніторинг localStorage

### Через DevTools:
1. F12 → Application → Local Storage → ваш домен
2. Має бути 3 ключі:
   - `previousScheduleHash`
   - `previousArchiveHash`
   - `previousArchiveLength`

### Через Console:
```javascript
// Перевірити всі збережені хеші
console.log('Schedule:', localStorage.getItem('previousScheduleHash'));
console.log('Archive:', localStorage.getItem('previousArchiveHash'));
console.log('Length:', localStorage.getItem('previousArchiveLength'));

// Очистити вручну (для тестування)
localStorage.clear();
```

## ✅ Критерії успіху

Сповіщення працюють правильно, якщо:

1. ✅ Хеші зберігаються після кожного fetch
2. ✅ Хеші завантажуються після перезавантаження
3. ✅ При зміні даних показується сповіщення
4. ✅ Сповіщення показуються у фоновому режимі
5. ✅ Діагностичний блок показує "✅ Збережено"

## 🎯 Реальний тест

### Найкращий спосіб перевірити:
1. Дочекайтеся реальної зміни даних на сервері (вечір/ранок)
2. Відкрийте додаток, скиньте історію
3. Дочекайтеся автоматичного оновлення
4. Згорніть браузер
5. Коли дані зміняться → отримаєте сповіщення! 🔔

## 📱 Специфіка платформ

### Desktop (Chrome/Edge/Firefox):
- ✅ Сповіщення працюють у фоні
- ✅ localStorage працює
- ✅ Service Worker працює

### Mobile Android (Chrome):
- ✅ Сповіщення працюють у фоні
- ✅ PWA сповіщення працюють
- ⚠️ Браузер має бути відкритий (згорнутий - OK)

### Mobile iOS (Safari):
- ⚠️ Обмеження з фоновими сповіщеннями
- ✅ localStorage працює
- ⚠️ PWA має обмеження
