## Як тестувати:

### 1. Перевірте дозвіл на сповіщення:
```javascript
// У консолі браузера:
Notification.permission
// Повинно бути: "granted"
```

### 2. Тестове сповіщення:
- Натисніть кнопку "🔔 Тестувати сповіщення" на сторінці
- Перевірте консоль - повинні з'явитися логи:
  ```
  🔔 ========== ПОКАЗ СПОВІЩЕННЯ ==========
  📱 Service Worker готовий: ...
  📱 Опції сповіщення: { silent: false, ... }
  ✅ ✅ ✅ Notification показано через Service Worker!
  ```

### 3. Тестування при зміні даних:
- Почекайте 5 хвилин (або змініть інтервал на 10 секунд для тесту)
- Коли дані зміняться, у консолі з'явиться:
  ```
  🔔 ========================================
  🔔 АРХІВ ЗМІНИВСЯ! Показую сповіщення
  🔔 ========================================
  🔔 Дозвіл на сповіщення: granted
  🔔 Викликаю showNotification...
  ```

### 4. Перевірте налаштування пристрою:

#### Android:
- Налаштування → Додатки → Chrome/Browser → Сповіщення → **Увімкнено**
- Налаштування → Звук → Сповіщення → **Не "Без звуку"**
- Перевірте, що телефон **не в режимі "Не турбувати"**

#### iOS/macOS:
- iOS: Налаштування → Safari → Сповіщення → **Дозволити**
- macOS: System Preferences → Notifications → Chrome/Safari → **Дозволити**
- Перевірте, що не ввімкнено **Focus/Do Not Disturb**

#### Desktop Chrome:
- chrome://settings/content/notifications
- Перевірте, що сайт у списку **"Дозволено"**
- Windows: Settings → System → Notifications → Chrome → **On**

### 5. Перевірка звуку:

**ВАЖЛИВО**: `silent: false` означає, що браузер/система **ПОВИННІ** відтворити звук, але:

- 🔊 **Android**: Системний звук сповіщення (налаштування → Звук → Звук сповіщення)
- 🔊 **iOS**: Системний звук Safari (якщо PWA додано на Home Screen)
- 🔊 **Desktop**: Системний звук браузера/ОС

**Якщо звуку немає**:
1. Перевірте гучність сповіщень на пристрої
2. Перевірте режим "Не турбувати"
3. На Android: Налаштування → Додатки → Chrome → Сповіщення → Звук → **Встановлено**
4. Спробуйте інший браузер

## Дебаг:

Якщо сповіщення не приходять:

1. **Перевірте консоль** - шукайте:
   - `🔔 Дозвіл на сповіщення: denied/default` → Треба надати дозвіл
   - `❌ Помилка` → Читайте повідомлення помилки
   - Відсутність логів `🔔 ЗМІНИВСЯ` → Дані не змінюються

2. **Примусово викличте сповіщення** у консолі:
```javascript
Notification.requestPermission().then(permission => {
  if (permission === "granted") {
    new Notification("Тест", {
      body: "Це тест",
      silent: false
    });
  }
});
```

3. **Перезапустіть браузер** після зміни налаштувань

4. **Перевірте Service Worker**:
```javascript
// У консолі:
navigator.serviceWorker.getRegistrations().then(regs => console.log(regs))
```

## Звіт про проблеми:

Якщо щось не працює, надішліть:
1. Скріншоти консолі браузера (DevTools → Console)
2. Платформу (Android/iOS/Desktop)
3. Браузер і версію
4. Чи є дозвіл на сповіщення (`Notification.permission`)
